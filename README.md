# Reboot Hub Organization Profile Source

This repository is prepared for the GitHub organization profile:

https://github.com/reboot-hub

The organization profile content lives in:

`profile/README.md`

When pushed to `reboot-hub/.github`, GitHub will display it on the organization homepage.

## Safety

This public profile contains only public brand information and public Reboot Hub URLs. Do not add credentials, private emails, customer information, supplier information, costs, margins, internal SOPs, backend URLs, or private business documents.
